# 잠깐만요 (아이폰용 가짜 전화)

회의나 대화 중 자리를 비워야 할 때, 버튼 하나로 전화가 걸려온 것처럼 만드는 앱입니다.
SwiftUI로 작성했고 iOS 17 이상에서 동작하도록 만들었습니다.

> 이 소스는 macOS가 없는 환경에서 작성되어 아직 컴파일해 보지 못했습니다.
> 첫 빌드에서 오류가 나면 오류 메시지를 그대로 알려 주세요.

## 무엇을 하나

| 기능 | 설명 |
| --- | --- |
| 예약 | 지금, 10초, 1분, 3분, 5분, 직접 입력(분) |
| 발신자 | 이름, 이름 아래 표시, 사진 |
| 실제 전화 화면 | CallKit으로 아이폰의 진짜 수신 화면을 띄웁니다. 잠금 화면에서도 울리고 벨소리와 진동은 폰 설정을 따릅니다. |
| 앱 안 화면 | 앱이 직접 그린 수신 화면. 발신자 사진이 보입니다. |
| AI 목소리 | 아이폰 내장 한국어 음성이 대사를 한 줄씩 읽고, 줄 사이에 대답할 틈을 둡니다. |
| 내 녹음 | 앱에서 바로 녹음한 목소리를 재생합니다. |
| 수화기 출력 | 목소리가 실제 통화처럼 수화기에서 나옵니다. 스피커 버튼으로 전환할 수 있습니다. |
| 꺼진 척 | 예약 중 화면이 새까맣게 보입니다. 두 번 두드리면 즉시 울리고 길게 누르면 취소됩니다. |
| 다시 전화 | 받지 않거나 거절하면 1분 뒤 두 번까지 다시 걸려옵니다. |
| 버튼 실행 | 단축어 동작 "가짜 전화 받기"를 동작 버튼이나 뒷면 탭에 연결할 수 있습니다. |

## 설치 방법 A: Mac이 있을 때

1. `Jamkkan.xcodeproj`를 Xcode로 엽니다. (열리지 않으면 `brew install xcodegen && xcodegen generate`)
2. Jamkkan 타깃의 Signing & Capabilities에서 본인 Apple ID 팀을 고르고, Bundle Identifier를 본인만의 값으로 바꿉니다.
3. 아이폰을 연결하고 실행합니다. 아이폰의 설정 > 개인정보 보호 및 보안 > 개발자 모드를 켜야 합니다.

무료 Apple ID로 설치하면 7일마다 다시 설치해야 합니다. 유료 개발자 계정(연 99달러)은 1년간 유지됩니다.

## 설치 방법 B: Mac이 없을 때 (Windows)

1. 이 폴더를 GitHub 저장소에 올립니다. `main` 브랜치에 올리면 `.github/workflows/build.yml`이 자동으로 돕니다.
2. 저장소의 Actions 탭에서 빌드가 끝나면 `Jamkkan-unsigned-ipa`를 내려받아 압축을 풉니다.
3. Windows에서 Sideloadly나 AltStore 같은 설치 도구로 `Jamkkan-unsigned.ipa`를 본인 Apple ID로 서명해 아이폰에 설치합니다.
4. 아이폰의 설정 > 일반 > VPN 및 기기 관리에서 본인 Apple ID를 신뢰하도록 설정합니다.

이 방법도 무료 Apple ID 기준 7일마다 다시 설치해야 합니다.
빌드가 실패하면 Actions에서 `build-log`를 내려받아 오류 부분을 확인할 수 있습니다.

## 버튼 하나로 실행하기

- 동작 버튼: 설정 > 동작 버튼 > 단축어 > "가짜 전화 받기"
- 뒷면 탭: 설정 > 손쉬운 사용 > 터치 > 뒷면 탭 > 단축어 선택
- 단축어 앱에서 "몇 초 뒤에 울릴까요" 값을 180으로 두면 3분 뒤에 울리는 버튼이 됩니다.
- 설정 메뉴 이름과 위치는 iOS 버전에 따라 조금 다를 수 있습니다.

## 알아 둘 점

- 실제 전화 화면에는 발신자 이름 아래에 앱 이름이 함께 표시됩니다. 그래서 앱 표시 이름을 "휴대전화"로 해 두었습니다. `Jamkkan/Info.plist`의 `CFBundleDisplayName`에서 바꿀 수 있습니다.
- 예약 중에는 앱을 닫지(위로 쓸어 올려 종료하지) 마세요. 폰을 잠그거나 다른 앱으로 넘어가는 것은 괜찮습니다.
- 집중 모드가 켜져 있으면 아이폰이 전화를 막을 수 있습니다. 집중 모드 설정에서 이 앱의 알림을 허용해 주세요.
- 더 자연스러운 목소리는 설정 > 손쉬운 사용 > 읽기 및 말하기 > 음성에서 한국어 고음질 음성을 내려받으면 앱의 목소리 종류에 나타납니다.
- 폰을 잠가도 예약이 살아 있도록 소리 없는 오디오를 재생하는 방식을 씁니다. 개인용으로는 문제없지만 App Store 심사에서는 거절될 수 있는 방식입니다.

## 파일 구성

```
Jamkkan/
  JamkkanApp.swift      앱 시작점, 화면 전환
  Models.swift          설정 값, 프리셋, 저장
  CallManager.swift     예약 → 울림 → 통화 → 종료 흐름, CallKit 연동
  AudioService.swift    벨소리, 진동, AI 음성, 녹음, 백그라운드 유지
  SetupView.swift       설정 화면
  CallViews.swift       대기, 수신, 통화 화면
  Components.swift      공통 버튼과 스타일
  FakeCallIntent.swift  단축어 동작
  Info.plist            권한과 백그라운드 설정
  ring.wav, silence.wav 벨소리와 무음 파일
project.yml             XcodeGen 설정
.github/workflows/      Mac 없이 빌드하는 워크플로
```
